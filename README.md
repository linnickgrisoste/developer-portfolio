# Linnick Grisoste · Portfólio

Site pessoal com os projetos, a trajetória e as ferramentas com que trabalho. É editorial, em português e inglês, com tema claro e escuro. A tipografia ganha volume ao interagir, e o nome do hero é uma cena 3D: as letras caem uma a uma na abertura.

Para quem gosta de explorar, há oito conquistas escondidas pelo site. Quem encontra todas ganha a coroa na sala de troféus em 3D e o modo dourado.

## Tecnologias

- Next.js 16 e React 19, com TypeScript
- Tailwind CSS 4 e shadcn/ui
- Motion e GSAP
- three.js, React Three Fiber e drei
- Componentes do [React Bits](https://reactbits.dev)
